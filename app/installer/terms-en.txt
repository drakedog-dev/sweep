SWEEP TERMS OF USE

1. Sweep is free, open-source software under the MIT licence (full text below). It is provided as is, without warranty of any kind; you use it at your own risk.

2. Sweep changes Windows settings, services and startup entries and removes files only when you press a button or flip a switch yourself.

3. Removed files go to a quarantine folder first, registry keys are backed up before cleaning and every switch can be turned back, so almost everything can be undone. Creating a Windows restore point before big changes is a good idea.

4. Sweep collects and sends no personal data and no telemetry. It contacts GitHub (api.github.com, github.com) to check for and download Sweep updates; this can be turned off in Settings. When you check for or install program updates, Windows Package Manager (winget) contacts the Microsoft package catalogue and downloads installers from the vendors' own sites; this happens only when you ask for it or turn on the daily check.

5. Sweep can be removed at any time with the standard uninstaller (Windows Settings, Apps).
