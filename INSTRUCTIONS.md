# Сборка Sweep.exe и установщика

Делается один раз на любой Windows 10 или 11. Ничего в системе не меняется, только собираются файлы.

## Шаг 1. Собрать Sweep.exe (5 минут)
1. Распакуйте архив в папку, например `C:\Sweep-build`.
2. Нажмите правой кнопкой на `build-exe.ps1` и выберите «Выполнить с помощью PowerShell».
   Если окно сразу закрывается, откройте PowerShell в этой папке и выполните:
   `Set-ExecutionPolicy -Scope Process Bypass` затем `.\build-exe.ps1`
3. При первом запуске скрипт поставит модуль ps2exe из галереи PowerShell (нужен интернет). Если спросит про доверие к репозиторию, ответьте Y.
4. В папке появится `Sweep.exe`. Его уже можно запускать двойным щелчком: он сам попросит права администратора.

## Шаг 2. Собрать установщик (5 минут)
1. Скачайте и установите Inno Setup 6: jrsoftware.org/isdl.php (бесплатно).
2. Запустите `build-setup.bat`.
3. В папке `Output` появится `Sweep-Setup-0.3.exe`. Это обычный установщик: Program Files, ярлык на рабочем столе, удаление через «Приложения».

## Если Windows или антивирус ругаются
Файл новый и без подписи, поэтому SmartScreen может показать «Неизвестное приложение». Нажмите «Подробнее» и «Выполнить в любом случае». Это нормально для всех новых программ до покупки сертификата подписи кода.
